## ২. ইনস্টলেশন ও লোকাল রান গাইডলাইন

### ডিপেন্ডেন্সি ইনস্টলেশন:
```bash
npm install
```

### ডেভেলপমেন্ট সার্ভার চালু:
```bash
npm run dev
```
ব্রাউজারে খুলুন: `http://localhost:3000`

### প্রোডাকশন বিল্ড:
```bash
npm run build
```
এটি `dist` ডিরেক্টরিতে অপ্টিমাইজড স্ট্যাটিক ফাইল তৈরি করবে।

## ৩. ফায়ারবেস (Firebase) কনফিগারেশন নির্দেশিকা

১. [Firebase Console](https://console.firebase.google.com)-এ একটি নতুন প্রজেক্ট তৈরি করুন।
২. Authentication থেকে **Email/Password** অথবা Google Sign-In চালু করুন।
৩. Cloud Firestore ডাটাবেস তৈরি করুন (Production or Test Mode)।
৪. প্রজেক্টের **Web App** তৈরি করে প্রাপ্ত কনফিগারেশন কি-গুলো `.env` ফাইলে লিখুন অথবা অ্যাডমিন প্যানেলের **ফায়ারবেস ডাটাবেস সেটিংস** ট্যাবে পেস্ট করুন:
```env
VITE_FIREBASE_API_KEY="AIzaSy..."
VITE_FIREBASE_AUTH_DOMAIN="your-app.firebaseapp.com"
VITE_FIREBASE_PROJECT_ID="your-app-id"
VITE_FIREBASE_STORAGE_BUCKET="your-app.appspot.com"
VITE_FIREBASE_MESSAGING_SENDER_ID="123456789"
VITE_FIREBASE_APP_ID="1:123456789:web:abcdef"
```
৫. `firestore.rules` ফাইলটি Firebase Console-এর Firestore Rules ট্যাবে পাবলিশ করুন।

## ৪. Netlify তে ডিপ্লয়মেন্ট (Deploy to Netlify)

প্রজেক্টটিতে ইতিমধ্যে `netlify.toml` ফাইল অন্তর্ভুক্ত রয়েছে।

### Netlify সেটিংস:
- **Build command**: `npm run build`
- **Publish directory**: `dist`
- **Node version**: 20 বা 22 LTS
- **SPA Rewrite Rule**: `netlify.toml`-এ `/* -> /index.html 200` স্বয়ংক্রিয়ভাবে কার্যকর আছে, ফলে `/admin` রিফ্রেশ করলে কোনো 404 ত্রুটি হবে না।

## ৫. সোর্স কোড ডাউনলোড (.ZIP)

অ্যাডমিন প্যানেলে লগইন করে বামদিকের **"সোর্স কোড ও আপডেট (.ZIP)"** মেনুতে গিয়ে **"সম্পূর্ণ সোর্স কোড ডাউনলোড (.ZIP)"** বাটনে ক্লিক করলেই সম্পূর্ণ প্রোডাকশন রেডি ক্লিন সোর্স কোড ডাউনলোড হয়ে যাবে।
